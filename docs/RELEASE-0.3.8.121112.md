# Sky's Building Pieces 0.3.8.121112

This is the NeoForge build for Minecraft 1.21.11. Use NeoForge 21.11.45 and
Java 21.

Existing pieces, recipes and save IDs carry forward. Matching glass walls still
join without a seam, and keep their borders at ends, posts and changes in colour.

Grass Slabs and Mineralogy remain optional. Back up your world before moving it
to 1.21.11, and update any add-ons to match this version of Minecraft and NeoForge.
