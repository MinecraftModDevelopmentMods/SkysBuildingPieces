# Sky's Building Pieces 0.3.7 for Minecraft 1.10.2

Grass steps and corners now keep their grass and snow edges, with grass visible
on the exposed ground beneath them. Use a shovel to make matching path pieces;
ordinary grass directly underneath becomes a path in the same action.

You can rebuild larger pieces in the crafting grid: stack two matching corners
for a step, or two matching steps for a slab.

Mineralogy support is now built in. Install Mineralogy to get steps and corners
for its 27 natural rocks, using its own textures and existing slabs. Remove the
separate Mineralogy piece add-on if you used an earlier test build; its saved
pieces are recovered by the core mod.

Building Pieces still works on its own and does not generate terrain. For the
shared grass behaviour, use Sky's Grass Slabs 1.1.1.110021 or later. Back up an
existing world before updating mods.
