# Building Pieces for Minecraft 1.17.1

This version brings the existing slabs, steps, corners, stairs, walls and panes
to Minecraft 1.17.1. It requires Forge 37.1.1 and Java 16.

Placement, joining, glass walls, grass, snow, waterlogging and shovel paths work
as before. Mineralogy rocks receive their steps and corners when Mineralogy is
installed. Grass Slabs remains optional; use its matching 1.17.1 version for
shared grass behaviour.

Recipe-book entries unlock from their matching ingredients. Existing palette
IDs and orientations are kept, along with custom item data and recovery of
supported older pieces. Back up a world before changing Minecraft versions,
then check a copy before continuing to play it.
