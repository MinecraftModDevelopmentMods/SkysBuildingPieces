# SkysBuildingPieces 0.3.9.110021

Grass steps and corners now match snowy terraces and cold, exposed ground.
Exposed vanilla and BOP grass beneath touching snowy pieces has matching snowy
sides and a snow-covered top. Directional slab placement can be turned off in
Mods > Config; normal placement remains enabled by default.

Back up your world before updating. Install the main jar on the client and
server. Saved pieces retain their materials and orientations; new smoothing
applies only to newly generated chunks.
